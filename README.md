## 🔧 Installation

Want to run this locally? Follow these simple steps:

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git (optional, for cloning)

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Abdelrhman612/abdelrhman-portfolio.git
   ```

2. **Navigate to project folder**
   ```bash
   cd abdelrhman-portfolio
   ```

3. **Open in browser**
   - Double-click `index.html` or
   - Use Live Server in VS Code for auto-reload

4. **Customize (Optional)**
   - Update `index.html` with your personal information
   - Replace `assets/cv.pdf` with your resume
   - Modify colors in `css/style.css` (look for `:root` variables)
   - Update social media links in `index.html`

## 📱 Responsive Design

The portfolio is fully responsive and optimized for all screen sizes:

| Device | Screen Size | Experience |
|--------|------------|------------|
| 🖥️ Desktop | > 1024px | Full experience with all animations |
| 💻 Laptop | 768px - 1024px | Optimized layout |
| 📱 Tablet | 481px - 768px | Collapsed menu, adjusted spacing |
| 📱 Mobile | < 480px | Single column, hamburger menu |

### 📊 Breakpoints
```css
/* Mobile */
@media (max-width: 480px) { ... }

/* Tablet */
@media (max-width: 768px) { ... }

/* Laptop */
@media (max-width: 1024px) { ... }
```
